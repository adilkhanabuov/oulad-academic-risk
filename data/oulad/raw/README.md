# OULAD raw files

Download OULAD from the official Open University page:

https://research.stem.open.ac.uk/ouanalyse/dataset/

Place the extracted CSV files in this directory. The current experiments read:

- `studentInfo.csv`
- `studentRegistration.csv`
- `studentVle.csv`

Do not commit the raw OULAD CSV files to this repository. They are excluded by `.gitignore`.
