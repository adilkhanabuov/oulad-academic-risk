# Precomputed result summaries

This directory contains the compact CSV and JSON summaries reported in the manuscript.

- `multiseed/`: five-seed neural models and component ablations.
- `baselines/`: tabular baseline comparisons.
- `hgb_module_ablation/`: HistGradientBoosting with and without `code_module`.
- `horizons/`: exact 2-, 4-, 6-, and 8-week evaluation summaries.
- `module_logit_bias/`: explicit scalar module-logit-bias control and evaluation without CCC.
- `student_cluster_bootstrap/`: 2,000-replicate cluster-bootstrap confidence intervals.

The raw dataset and large intermediate weekly-feature tables are not included.
